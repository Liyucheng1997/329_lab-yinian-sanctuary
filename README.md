# 一念 · 线上禅院

一个沉浸式电子念佛与冥想网站。墨色留白、一笔圆相、浮动光尘，配以实时合成的佛乐与法器声，营造空而静的线上修行空间。

## 功能

- **木鱼 / 念珠 / 法轮 / 观息**：四种修行方式，点击、空格或拖动。法轮对应六字真言，念珠与木鱼对应六字佛号，观息为 4-2-4-2 秒呼吸。
- **伴乐**（生成式，永不重复）：
  - 空山：低沉持续音、疏落的古琴拨弦与泛音、偶尔一声颂钵；
  - 梵音：僧众低声念诵六字，一句八拍，唱三句歇一句，屏幕上的字随唱诵点亮；
  - 晨钟：梵钟一撞，笙簧缓起，风铃偶响，间或一段箫声。
- **节律**（自动修行时，与伴乐共用一个节拍时钟）：
  - 平稳：一拍一击，每八拍一声磬；
  - 念佛：木鱼随字，磬起句，引磬落在"佛"字；
  - 法鼓：八分音符木鱼与法鼓、磬、引磬相和。
- 击打时的涟漪、圆相微光与字句点亮都按音频时间对齐。每满 108 次有一声磬。
- 细雨（含檐滴）、山风、溪流声景；伴乐、法器、声景三路音量；速度 40–96 拍／分。
- 静：7 秒无操作后界面自动隐去，只留法器与数字；沉浸模式可全屏。
- 设置保存在本机浏览器中。快捷键：空格 敲击 · A 自动 · M 伴乐 · Esc 退出。

## 本地运行

这是纯静态网站，无需安装前端依赖。安装 Python 3 后，在项目目录运行：

```sh
python -m http.server 53129 --bind 127.0.0.1 --directory dist
```

浏览器访问 <http://127.0.0.1:53129>。也可以用任意静态服务器托管 `dist/`。

## 文件结构

```text
dist/
  index.html    页面结构
  style.css     主题、响应式布局与动画
  audio.js      声音引擎：法器模态合成、殿堂混响、节拍时钟、生成式伴乐与声景
  app.js        交互、节律、圆相与光尘绘制
  wood.png      AI 生成的木鱼场景图片
```

## 使用说明

声音需要先点击"入殿"才能播放。所有伴乐、法器与声景都用 Web Audio 在浏览器里实时合成，不含任何录音文件。修行计数仅保存在当前页面内存中，刷新后重置。页面切到后台时伴乐与自动修行会继续。

中文字体通过 Google Fonts 加载；无法联网时使用系统中文衬线字体。支持 WebMCP 的浏览器可以通过 `select_meditation_practice` 切换修行方式。
