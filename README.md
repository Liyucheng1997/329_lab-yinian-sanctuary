# 一念 · 线上禅院

一个沉浸式电子念佛与冥想网站。以深松绿、旧金色、暗光木鱼与环境声景，营造安静的线上修行空间。

## 1.0 功能

- **敲木鱼**：点击或空格敲击，配合合成音效、回弹动画与本次计数。
- **拨念珠**：点击、键盘或左右拖动念珠，保持念念相续的节奏。
- **转法轮**：点击或拖动带惯性的法轮，统计完成圈数。
- **呼吸冥想**：吸气 4 秒、停留 2 秒、呼气 4 秒、停留 2 秒；支持开始和暂停。
- 自动修行与节奏调节、音效开关、音量调节、静心计时。
- 无声、细雨、山风和溪流声景。
- 沉浸模式、移动端布局与键盘操作。

## 本地运行

这是纯静态网站，无需安装前端依赖。安装 Python 3 后，在项目目录运行：

```sh
python -m http.server 53129 --bind 127.0.0.1 --directory dist
```

浏览器访问 <http://127.0.0.1:53129>。也可以用任意静态服务器托管 `dist/`。

## 文件结构

```text
dist/
  index.html    页面结构
  style.css     主题、响应式布局与动画
  app.js        交互、Canvas 绘制与 Web Audio 声音
  wood.png      AI 生成的木鱼场景图片
```

## 使用说明

声音需要先点击页面才能播放。木鱼等音效和环境声使用 Web Audio 实时合成，不是真实录音。修行计数仅保存在当前页面内存中，刷新后重置。页面切到后台时自动修行暂停。

中文字体通过 Google Fonts 加载；无法联网时使用系统中文衬线字体。支持 WebMCP 的浏览器可以通过 `select_meditation_practice` 切换修行方式。
